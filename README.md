# Neon Nexus

Create a futuristic, premium, highly interactive personal portfolio website for a Software Developer, Data Scientist, Data Analyst, and Full Stack Developer.

Tech Stack:

- React 19

- TypeScript

- Vite

- Tailwind CSS

- Framer Motion

- GSAP animations

- Three.js / React Three Fiber

- React Icons

- Lenis Smooth Scroll

- React Router

- EmailJS contact form

- Supabase backend

- Responsive Design

- Dark Theme only

- Glassmorphism + Cyberpunk + Apple + Tesla inspired UI

- SEO optimized

- Fast loading

- Production ready

The website should look like something from 2035 with smooth animations, glowing effects, floating objects, particle backgrounds, animated gradients and modern transitions.

Use black, deep blue, purple and cyan neon colors.
